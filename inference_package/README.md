# RAFA-PC Stage 4 Inference Package

This package provides everything needed to run high-fidelity audio generation using the graduated Stage 4 "Joint Hardening" model.

## Features
- **Naked Implementation**: Pure functional tensor operations. No `nn.Module` or `transformers` dependency.
- **Blackwell Optimized**: Designed specifically for `sm_120` register bounds and Triton-accelerated prime lattice summary.
- **Joint Binding**: The denoiser is physically bound to the `NakedRAFA` core's internal "thought" state.

## Contents
- `infer_stage4.py`: Main inference driver.
- `checkpoint.pt`: The graduated Stage 4 joint weights (80M parameters).
- `samples/`: Representative audio samples generated by this model.
- `lib_blackwell.py`, `triton_kernels.py`, `diffusion_utils.py`: Core logic dependencies.

## Usage

Ensure you have a `cuda` enabled environment with `torch` and `triton` installed.

### Basic Generation
```bash
python infer_stage4.py --ckpt checkpoint.pt --out output.wav --mode 1 --spectrum 2
```

### Parameters
- `--mode`: The semantic mode ID (0-9).
  - `1`: Engine
  - `2`: Voice
  - `3`: Impact
  - `4`: Drone
  - `5`: Bell
- `--spectrum`: The spectral bias (0-3).
  - `0`: Dark
  - `1`: Warm
  - `2`: Bright
  - `3`: Broadband
- `--steps`: Number of diffusion steps (default 50).
- `--seed`: Random seed for reproducible generation.

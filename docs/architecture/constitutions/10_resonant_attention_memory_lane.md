# Constitution: Resonant Attention / Post-Token Memory Lane

## Identity

This lane tests whether RAFA can form a phase-native relational memory substrate.
It is not the audio engine and it is not a normal transformer hidden-state lane.

## Thesis

Local phase-law objects should become addressable by resonance. A packet,
childworld, grandchild, or dense signature becomes token-like only after it can be
retrieved, composed, and causally used as an operator.

## What This Lane Exists To Prove

- RAFA attention can select laws, not just mix content vectors.
- Queries can be unresolved phase/rational/support tensions.
- Keys can be advertised q/arc/support/lifecycle laws.
- Values can be phase or branch operators.
- Child and grandchild law objects can be retrieved without explicit IDs.
- More law objects can improve selectivity rather than just add noise.

## Core Allowed Modules

- unit-phasor lattice state
- q-profile and Ramanujan compatibility
- major/minor arc compatibility
- support geometry
- child and grandchild law records
- dense relational signatures as compressed carriers
- learned residual scoring, if geometric components remain reported

## Forbidden Move

This lane is not allowed to call dense dot-product routing "RAFA attention" unless
the geometric score spine, operator-value causality, and retrieval/composition
assays are reported.

It is also not allowed to call a packet or signature a RAFA token just because it
exists. Token-like status must be earned.

## Central Evaluator

- resonant child retrieval
- cross-depth composition
- interference selectivity
- operator causality
- unit-phasor and gauge-invariance contracts

## Current Evidence

Circleworld has a local QKV-shaped precursor:

- `branch_law_version = relational_qkv_v2`
- `_relational_branch_attention(...)`

This demonstrates local branch coupling, not full resonant memory. The newest
child-carrier bridge results show that child carriers can convert into
parent-mode ontology under carrier-only conditions, but retrieval and
composition across child/grandchild law banks remain unproven.

## Success Signature

- partial relational queries retrieve compatible law objects above decoys
- selected values causally change phase or branch state
- parent-child-grandchild composition improves q/arc/support fit without world jump
- selectivity survives larger banks of children and grandchildren
- audio bridge metrics do not expose the result as decorative ontology

## Failure Signature

- retrieval works only through stored IDs or labels
- dense learned residual dominates while geometry does not matter
- values are summaries that do not causally affect state
- many child worlds create noise rather than sharper selection
- internal ontology improves while audio continuity or operator causality remains zero

## Constitutional Verdict

Scaffolded as a research lane. It has a clear precursor in Circleworld, but it is
not yet validated as RAFA attention or as a post-token memory substrate.

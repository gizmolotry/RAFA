# Constitution: Conditioned Logic Diagnostic Lane

## Identity
This lane is the probe bench for relational persistence. It is not the product surface. It exists to answer whether the chamber actually binds the right attractor under controlled tasks.

## Thesis
If the model has any real relational mechanism, it should survive small logic grids, decoy pressure, and recurrence-depth comparisons.

## What This Lane Exists to Prove
- deeper recurrent settling can help some checkpoints
- success is checkpoint-family dependent
- anchor and intermediate consistency are not automatically the active ingredient

## Core Allowed Modules
- relational probes
- logic grids
- recurrence-depth sweeps
- anchor / consistency toggles

## Central Evaluator
- success rate
- mean persistence
- mean final rank
- target margin vs decoys

## Best Current Evidence
Cross-family diagnostic summary:
- `prompt_anchor20` best `ns4` rows reached `success_rate = 0.50`
- `prompt_real_quick` best `ns4` rows reached `success_rate = 0.25`
- `bridge_s8000` rows all failed

## Success Signature
- conditioned families improve under deeper recurrence
- decoy rejection rises
- persistence improves, not just transient rank

## Failure Signature
- late attractor hits with poor persistence
- bridge-family non-recovery
- anchor pressure hurting rather than helping

## What This Lane Is Not Allowed to Claim
- robust reasoning
- generalized arithmetic competence
- semantic truthfulness

## Constitutional Verdict
Useful diagnostic lane with narrow positive signal. It proves the repo can detect relational effects, but not that RAFA has solved logic.

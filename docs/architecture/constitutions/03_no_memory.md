# Constitution: no_memory

## Identity
`no_memory` is the knockout that removes motif/relational memory from the parent hybrid.

## Thesis
If memory is important, it should preserve meaningful attractors rather than just preserve noise.

## What This Branch Exists to Prove
- whether long-horizon memory contributes to stable structure and anti-collapse behavior

## Removed Component
- motif memory / explicit memory contribution

## Everything Else It Inherits
- parent hybrid stack
- Hyena transport
- clutch routing
- Ramanujan-aware substrate
- diffusion output

## Central Evaluator
- Path-B against the parent
- degradation in coherence without catastrophic collapse

## Success Signature
As an ablation, success means showing that memory is a contributor to the stability attractor, not a myth or redundant ornament.

## Failure Signature
- identical behavior to the parent
- or strong evidence that memory was preserving junk rather than meaningful structure

## Current Constitutional Verdict
Inconclusive but informative. Memory appears contributory, but the repo does not yet justify treating it as the sole source of relational persistence.

# RAFA Branch Stocktake

This document takes stock of the actual RAFA branches in the repo and assigns each one a specific constitution.

A constitution is not a vibe or a slogan. It defines:
- what the branch is for,
- what it is allowed to optimize,
- what modules are central vs incidental,
- what evaluator decides success,
- what failure looks like,
- and what that branch is not allowed to claim.

## The Main Branch Families

### 1. Graduation Pack / Parent Hybrid
- Family: parent artifact
- Core claim: a hybrid of Hyena, clutch routing, memory, Ramanujan structure, and diffusion can produce stable, structured audio.
- Status: proven working for audio generation.
- Key evidence: `0.0%` collapse and strong Path-B structure, with ledgered historical role as the anchor artifact.
- Constitution: [01_graduation_pack.md](constitutions/01_graduation_pack.md)

### 2. Local Knockout Ablations
- Family: controlled removals from the parent hybrid
- Core claim: no single legacy module is the entire engine, but some are contributors to the stability attractor.
- Status: inconclusive but informative.
- Members:
  - [02_no_ramanujan.md](constitutions/02_no_ramanujan.md)
  - [03_no_memory.md](constitutions/03_no_memory.md)
  - [04_no_slow_clock.md](constitutions/04_no_slow_clock.md)

### 3. Subtractive Fork / Mutilated RAFA
- Family: subtractive purity fork
- Core claim: if phase-native structure is real, maybe we can strip the hybrid down until the essential law remains.
- Status: failed.
- Key evidence: stage-4 blowup, `CentVar ~ 408,993`, perceptual collapse into high-gain noise.
- Constitution: [05_subtractive_fork.md](constitutions/05_subtractive_fork.md)

### 4. Positive Replacement / Circleworld
- Family: positive replacement architecture
- Core claim: intelligence should live inside recursive structural mass laws, not in a hybrid stack propped up by external modules.
- Status: scaffolded, not yet validated.
- Key evidence: lineage-local promotion machinery now runs, but the first active/passive packet rules do not improve major-arc mass yet.
- Constitution: [06_positive_replacement.md](constitutions/06_positive_replacement.md)

## Repo-Level Summary

### What is actually proven
- RAFA can generate stable, non-collapsed audio.
- The hybrid parent/hypercube regime is a real audio system, not a toy.
- Prompt-conditioning can perturb the system, but only weakly so far.

### What is partially real but not promoted
- Deeper recurrence can help some conditioned logic families.
- Structural steering can be injected without collapse.
- Circleworld-style promotion machinery can run and produce promotable packets.

### What is not yet earned
- strong semantic control
- robust logic solving
- a working low-rank impedance head
- a validated multiscale memory claim
- a positive replacement model that beats the hybrid on its own terms
- a validated RAFA attention or post-token memory substrate

## Governance Rule

No branch gets to borrow legitimacy from another branch.

- The hybrid parent is allowed to claim stable audio.
- The logic lane is allowed to claim only what its probes support.
- The semantic steering lane is allowed to claim only what the bifurcation evaluator supports.
- The positive replacement line is allowed to claim only what its Circleworld evaluator supports.

That separation is the only way this repo stays scientifically honest.

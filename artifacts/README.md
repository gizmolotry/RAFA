# Artifacts

This folder holds bulky run outputs, historical checkpoints, bundles, and legacy material.

## Structure
- `checkpoints/runs/`: historical diffusion and run-specific checkpoint folders
- `checkpoints/stages/`: stage-oriented training checkpoints
- `checkpoints/archive/`: old archive checkpoint roots
- `bundles/`: dense metric bundles and exported packs
- `legacy/`: old leftovers not needed for day-to-day navigation

Note:
Some original top-level checkpoint paths are preserved as hidden junctions for compatibility.
